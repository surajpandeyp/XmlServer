# XmlServer

## 🔥 About the Project

**XmlServer** is a **CTF-style vulnerable web application** created to **learn and practice XML security vulnerabilities**.

The main focus of this project is on **XML parsing flaws**, especially those that appear in **real-world applications**, **CTF challenges**, and **VAPT/security assessments**.

⚠️ **Note:**  
This project is **intentionally vulnerable** and is designed **only for educational, CTF practice, and security research purposes**.  
It must **not** be used in production environments.

---

## 🎯 Project Objectives

- Understand how XML parsing works on the backend
- Practice common XML-based vulnerabilities
- Develop an attacker mindset for security testing
- Build a realistic CTF-style lab environment
- Understand frontend–backend interaction

---

## 💣 Vulnerabilities Included (Intentionally)

- Insecure XML parsing
- XML External Entity (XXE) vulnerability
- Improper input validation
- Misconfigured backend logic (for CTF purposes)

---

## 🛠 Tech Stack

### Backend
- Node.js
- Express.js
- MySQL
- XML Parser (intentionally insecure configuration)

### Frontend
- React.js
- JavaScript
- HTTP requests for sending XML payloads
